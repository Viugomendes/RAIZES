# Raízes

Site privado com a árvore genealógica de uma família: uma página para cada
pessoa e uma árvore desenhada a partir dos dados.

Este README será completado ao longo da primeira entrega. O plano completo
está em [docs/plano.md](docs/plano.md).

## Comandos do dia a dia

Abra o terminal na pasta do projeto (no VS Code: Terminal > Novo terminal).

```powershell
# Ativar o ambiente virtual (uma vez por terminal aberto)
.\.venv\Scripts\Activate.ps1

# Rodar os testes
python manage.py test
```
